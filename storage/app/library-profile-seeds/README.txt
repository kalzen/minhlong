  php artisan db:seed --class=Database\\Seeders\\LibraryProfileDocumentsSeeder --force

  - Minhlong-group.pdf
  - Minhlong-power.pdf

Seeder ưu tiên thư mục này trước các đường dẫn khác trong mã nguồn.
